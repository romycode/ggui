# Archivo

Documentos **congelados**. No se actualizan, no se corrigen, no se borran.

Cada fichero describe lo que se decidió construir en la fecha de su nombre.
Si el código de hoy no coincide, el documento no está equivocado: está
superado. Para consultar el estado actual, ver los documentos vivos en
`docs/` o la documentación de los paquetes (`go doc`).

Cuando una decisión cambie, se escribe un documento nuevo con fecha nueva.
Editar uno de estos destruye justo lo que los hace útiles: saber qué se
sabía y qué se creía en un momento dado.

## Contenido

- `specs/` — diseño acordado antes de implementar.
- `plans/` — planes de implementación, en tareas, con enfoque TDD.

## Convención

- Nombre con fecha (`YYYY-MM-DD-*.md`) = congelado, vive aquí.
- Nombre sin fecha = documento vivo, vive en `docs/`.
