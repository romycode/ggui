func TestEmitLeavesExistingOutputOnParseFailure(t *testing.T) {
	dir := t.TempDir()

	out := filepath.Join(dir, "keysyms.gen.go")

- [ ] **Step 5: Implement deterministic rendering**

`Render` must create sorted slices for each map:

- sort `Names` lexicographically by string;
- sort `CanonicalNames` and `Runes` numerically by keysym;
- render numeric keysym and rune values as zero-padded lowercase hex with at
  least four digits;
- quote strings with `strconv.Quote`;
- pass the completed buffer to `format.Source` and return
  `keysymgen: format generated Go: %w` on failure.

Use the exact declarations and order from `TestRenderDeterministicGo`.
`Generate` is exactly parse then render:

```go
func Generate(r io.Reader) ([]byte, error) {
	tables, err := Parse(r)
	if err != nil {
		return nil, err
	}
	return Render(tables)
}
```

- [ ] **Step 6: Implement failure-safe emission**

`Emit` opens the input, calls `Generate`, creates a temporary file in the
destination directory with `os.CreateTemp`, applies mode `0o644`, writes and
closes it, and only then calls `os.Rename` over the destination. A deferred
`os.Remove(tempName)` cleans up every failure path. Every filesystem error
includes the affected path.

- [ ] **Step 7: Implement the standalone command**

Create `main.go`:

```go
package main

import (
	"fmt"
	"os"

	"github.com/romycode/ggui/cmd/keysymgen/internal/keysymdata"
)

const (
	defaultInput  = "third_party/libxkbcommon/xkbcommon-keysyms.h"
	defaultOutput = "keyboard/keysyms.gen.go"
)

func main() {
	if err := run(defaultInput, defaultOutput); err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
}

func run(inputPath, outputPath string) error {
	return keysymdata.Emit(inputPath, outputPath)
}
```
